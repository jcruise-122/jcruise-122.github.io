About this generator

  • This calls a real hosted text-to-video model with audio generation enabled; the page does not fake or simulate the result.
  • AI video generation is not free to operate at scale. The model provider may charge the account owner for each request.
  • GitHub Pages hosts static websites only. A separate server is needed to protect the provider key and relay generation requests.
  • To activate it, deploy the included backend on a server with environment secrets, then set the backend URL in video-config.js.
