Welcome!

Python is a general-purpose programming language used for automation, websites, science, data, and many other kinds of software. You do not need prior programming experience for this guide. Work through the chapters in order, type the examples yourself, and experiment with changing them.

How to learn effectively

  1. Write and run each example rather than only reading it.
  2. Before running a program, predict what it will do.
  3. When something breaks, read the last line of the error first, then inspect the line it names.
  4. Do the exercises from memory, and build small projects between chapters.

Learning goal: by the end, you should be able to design, test, and explain small Python programs, and know what to study next. “Advanced” is a journey, so use the later chapters as a foundation for deeper practice.

1. Set up Python

Install a current Python 3 release from python.org, or use a trusted online Python editor if installation is not possible. On Windows, the launcher is often py; on macOS and Linux, use python3. Check your installation in a terminal:

python3 --version

Create a file named hello.py, then run it from that file’s folder with python3 hello.py (or py hello.py on Windows). A code editor makes writing easier, but a plain text editor is enough to start.

Important: use Python 3. The older Python 2 is no longer supported.

2. Your first program

print("Hello, world!")
print("I am learning Python.")

print() displays information. Text goes inside quotation marks. Python runs statements from top to bottom. Lines beginning with # are comments for people reading the code:

# This is a comment
print("Comments explain why code exists.")
Try it: print your name, a hobby, and one reason you want to learn programming.

3. Values, variables, and basic operations

A variable is a name that refers to a value. Use descriptive names in snake_case.

name = "Amina"       # str: text
age = 16             # int: whole number
height = 1.62        # float: decimal number
is_learning = True   # bool: True or False

print(name, age)
print(age + 1)
print(type(height))

Common arithmetic operators are +, -, *, / (division), // (floor division), % (remainder), and ** (power). Use parentheses to make the order clear.

total_minutes = 135
hours = total_minutes // 60
minutes = total_minutes % 60
print(hours, "hours and", minutes, "minutes")

Get user input with input(). It always returns text, so convert it before doing numeric calculations:

age_text = input("How old are you? ")
age = int(age_text)
print("Next year you will be", age + 1)
Try it: ask for two numbers, convert them to float, and print their sum and product.

4. Decisions and loops

Use if, elif, and else to choose what happens. Indentation is part of Python’s syntax—normally use four spaces.

score = 72
if score >= 80:
    print("Great work")
elif score >= 50:
    print("Keep practicing")
else:
    print("Review the basics")

Comparisons include ==, !=, <, <=, >, and >=. Combine conditions with and, or, and not. A single = assigns a value; == compares two values.

A for loop visits items. range(5) produces 0 through 4. A while loop repeats while its condition is true.

for number in range(1, 4):
    print(number)

countdown = 3
while countdown > 0:
    print(countdown)
    countdown -= 1
print("Go!")

Use break to leave a loop and continue to skip to its next iteration. Make sure a while loop can eventually stop.

Try it: ask for a whole number and report whether it is positive, negative, or zero. Then print the multiplication table for that number.

5. Collections: lists, tuples, dictionaries, and sets

A list is an ordered, changeable collection. Positions start at index 0.

colors = ["blue", "green", "gold"]
print(colors[0])
colors.append("red")
colors[1] = "purple"
print(len(colors))

for color in colors:
    print(color)

A tuple is an ordered collection that is usually used for values that belong together and should not be changed. A set stores unique values and is useful for membership checks and removing duplicates.

point = (4, 7)
unique_numbers = {2, 2, 5, 7}
print(unique_numbers)  # {2, 5, 7}

A dictionary maps keys to values. Keys are commonly strings.

student = {"name": "Amina", "score": 82}
student["score"] = 88
student["country"] = "Zambia"
print(student.get("email", "No email recorded"))

for key, value in student.items():
    print(key, value)

Choose a collection based on what you need: list for an ordered sequence, tuple for a fixed group, set for unique membership, and dictionary for looking up values by key.

Try it: store three favorite books in a list and print them with numbers. Then create a dictionary for one book with its title, author, and year.

6. Functions

Functions package reusable work. Give them clear names, pass inputs as parameters, and return a result when appropriate.

def rectangle_area(width, height):
    """Return the area of a rectangle."""
    return width * height

area = rectangle_area(5, 3)
print(area)

return sends a result back to the caller. If a function has no explicit return, it returns None. Parameters can have defaults:

def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

print(greet("Amina"))
print(greet("Ben", greeting="Welcome"))

Keep functions focused: one function should have one clear job. Variables created inside a function are local to it; pass information in instead of relying on hidden global state.

Try it: write is_even(number) that returns True for even integers and False otherwise. Add a second function that uses it to count even numbers in a list.

7. Strings and formatting

Strings are text. They have useful methods, and they are immutable: methods return new strings rather than changing the original.

message = "  Python is fun  "
clean = message.strip()
print(clean.lower())
print(clean.upper())
print(clean.replace("fun", "powerful"))
print("Python" in clean)

Use an f-string to place values into text cleanly:

name = "Amina"
score = 88
print(f"{name} earned {score}%.")
print(f"Half the score is {score / 2:.1f}.")

Strings can be indexed and sliced much like lists: word[0] gets the first character, and word[:3] gets the first three characters.

Try it: ask for a sentence and print its character count, uppercase version, and first word. Consider what should happen for empty input.

8. Files and errors

Use with to open a file; it closes the file automatically, even if an error occurs. The example writes text to a file in the program’s current folder.

with open("notes.txt", "w", encoding="utf-8") as file:
    file.write("Python practice\n")

with open("notes.txt", "r", encoding="utf-8") as file:
    contents = file.read()

print(contents)

Modes include "r" (read), "w" (write and replace existing contents), and "a" (append). Handle expected errors specifically:

try:
    with open("scores.txt", encoding="utf-8") as file:
        text = file.read()
except FileNotFoundError:
    print("The scores file does not exist yet.")

Catch errors you can meaningfully handle. Avoid a bare except: that hides unrelated problems. For numeric input, catch ValueError if the user enters something that cannot be converted.

Try it: create a small program that asks for a note, appends it to a text file, then reads and prints all saved notes.

9. Modules, packages, and virtual environments

A module is a Python file you can reuse. Import standard-library modules for common tools:

import random

secret = random.randint(1, 10)
print(secret)

Put your own reusable functions in another .py file and import them by filename (without the extension). For larger projects, use a virtual environment so project dependencies do not interfere with each other.

python3 -m venv .venv
# Activate it, then install packages with:
python -m pip install package-name

Activation differs by operating system: on macOS/Linux use source .venv/bin/activate; on Windows PowerShell use .venv\Scripts\Activate.ps1. To leave the environment, run deactivate. Do not install a package just because you can—first check whether the standard library already solves the problem.

10. Classes and objects

A class defines a kind of object that combines data and behavior. Use classes when they make a program’s concepts clearer; not every problem needs one.

class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Deposit must be positive")
        self.balance += amount

account = BankAccount("Amina", 100)
account.deposit(25)
print(account.owner, account.balance)

__init__ initializes a new instance. self refers to that instance. Instance methods can read or update its attributes. Classes are especially helpful when several pieces of related state and behavior belong together.

Try it: create a Book class with title and author attributes and a method that returns a short description.

11. Pythonic tools: comprehensions, iterators, and generators

A list comprehension creates a list from an iterable in a compact, readable way:

squares = [number * number for number in range(1, 6)]
even_squares = [n * n for n in range(10) if n % 2 == 0]
print(squares)
print(even_squares)

Do not compress complicated logic into a one-liner. A regular loop is often clearer. An iterable is something you can loop over. A generator produces values one at a time, which can save memory for large sequences:

def count_up_to(limit):
    number = 1
    while number <= limit:
        yield number
        number += 1

for value in count_up_to(3):
    print(value)

yield pauses a generator and resumes it on the next iteration. This is useful for streams or values that need not all be stored at once.

12. Type hints and data classes

Type hints document the kinds of values a function expects and returns. Python does not enforce these hints at runtime by default, but editors and optional static-analysis tools can use them to catch mistakes.

def average(numbers: list[float]) -> float:
    if not numbers:
        raise ValueError("numbers must not be empty")
    return sum(numbers) / len(numbers)

A data class is a convenient way to define a class mainly used to hold data:

from dataclasses import dataclass

@dataclass
class Student:
    name: str
    score: int

student = Student("Amina", 88)
print(student)

Use hints to communicate intent, not as a substitute for tests or good design.

13. Testing, debugging, and clean code

Tests check that code behaves as expected. Python includes unittest; here is a small example:

import unittest
from my_math import is_even

class TestIsEven(unittest.TestCase):
    def test_even_number(self):
        self.assertTrue(is_even(4))

    def test_odd_number(self):
        self.assertFalse(is_even(5))

if __name__ == "__main__":
    unittest.main()

Save this as a test file and run it with python -m unittest. Test normal cases, boundary cases (like zero or an empty list), and invalid inputs. A failing test is useful information: reproduce it, inspect the traceback, make a small fix, and run the test again.

  • Choose descriptive names and keep functions small.
  • Use consistent formatting; Python’s common style conventions are described in PEP 8.
  • Remove duplicated logic when a well-named function would clarify it.
  • Use version control such as Git to track changes as projects grow.

14. Algorithms and performance

An algorithm is a set of steps for solving a problem. Big-O notation describes how the amount of work grows as input grows; it is not an exact time measurement.

O(1)
Constant-time lookup, such as a typical dictionary key lookup.
O(n)
One pass through n items.
O(n²)
Comparing every item with every other item using nested loops.

For example, searching a list one item at a time is O(n). Checking membership in a set is typically much faster for large collections. Choose a clear solution first, then measure real performance before optimizing.

def find_name(names, target):
    for name in names:
        if name == target:
            return True
    return False

Learn common data structures (lists, dictionaries, sets, queues, trees) and practice problem solving. Correctness and readability come before clever optimization.

15. Concurrency basics

Concurrency lets a program make progress on multiple tasks. For many network or other waiting-heavy tasks, asyncio can coordinate work without blocking on each wait. It is an advanced topic; learn normal functions and error handling first.

import asyncio

async def greet_after_wait():
    print("Starting")
    await asyncio.sleep(1)
    print("Finished waiting")

asyncio.run(greet_after_wait())

async def defines a coroutine, and await pauses it while an asynchronous operation completes. Async code is useful when libraries support it and a program spends time waiting. It does not automatically make CPU-heavy work faster. Threads and processes are other tools, each with trade-offs.

16. Projects and your next steps

Projects turn concepts into skills. Build in stages: make a simple version work, test it, then add features.

Beginner
Number guessing game, quiz, unit converter, or grade calculator.
Intermediate
To-do list that saves data, contact book, or command-line expense tracker.
Advanced
Well-tested package, web API, data analysis project, or an async network client.

A project workflow

  1. Describe the problem and list the smallest useful features.
  2. Break the work into functions or modules.
  3. Build one feature at a time and run the program often.
  4. Handle expected bad input and errors.
  5. Write tests, explain how to run it, and track changes with Git.

Suggested study path

First become comfortable with chapters 1–8 and build two small programs. Then learn modules, classes, testing, and Git. After that, choose a direction—web development, automation, data science, AI, or systems—and learn the tools that fit it. Advanced programming comes from practice reading, building, testing, and improving real projects.

Remember: errors are a normal part of programming. Read them carefully, try one change at a time, and keep going. You do not need to memorize everything; knowing how to break a problem down and find reliable documentation is a core programming skill.
